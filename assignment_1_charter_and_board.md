---

## 4. Team Communication Rules

1. Team members should communicate respectfully with one another.
2. Members should provide progress updates when working on assigned tasks.
3. Members should inform the team when they encounter a technical problem
   that may delay their task.
4. Important project decisions should be communicated to the whole team.
5. Members should respond to project-related questions within a reasonable
   period.
6. Urgent problems should be communicated through the team's agreed quick
   communication channel.

---

## 5. GitHub Collaboration Rules

The team follows a feature-branch workflow.

Members should:

1. Work on their assigned feature or task.
2. Create or use an appropriate feature branch.
3. Avoid directly editing the `main` branch.
4. Commit changes with clear commit messages.
5. Push their branch to GitHub.
6. Create a Pull Request when their work is ready for review.
7. Allow another team member to review the changes.
8. Resolve any issues identified during review.
9. Merge the Pull Request into `main` after approval.
